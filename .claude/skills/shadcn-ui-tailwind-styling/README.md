# shadcn-ui-tailwind-styling

## 1. Công dụng

Dùng để thiết kế và xây dựng giao diện UI hiện đại, dễ truy cập, responsive, dựa trên shadcn/ui, Radix UI và Tailwind CSS. Skill này cũng hỗ trợ tùy biến theme, dark mode, component system và cả thiết kế visual theo hướng canvas khi cần tạo bố cục ấn tượng hơn.

## 2. Lợi ích

- Tạo UI nhanh nhờ bộ component có sẵn và dễ ghép nối.
- Đảm bảo accessibility tốt hơn nhờ Radix UI và các pattern chuẩn.
- Dễ làm responsive, mobile-first, và hỗ trợ dark mode.
- Duy trì consistency nhờ design tokens, utility classes và hệ thống theme rõ ràng.
- Phù hợp cho cả giao diện app, dashboard, form, dialog, navigation, bảng dữ liệu, command palette.

## 3. Dùng trong trường hợp nào?

- Khi làm UI bằng React-based framework như Next.js, Vite, Remix, Astro.
- Khi cần component accessible như form, modal, menu, table, tabs, toast, drawer.
- Khi muốn style bằng Tailwind CSS theo hướng utility-first.
- Khi cần layout responsive, mobile-first, có dark mode.
- Khi xây design system hoặc chuẩn hóa token màu sắc, typography, spacing.
- Khi cần prototype UI nhanh nhưng vẫn giữ chất lượng thiết kế tốt.

## 4. Không nên dùng trong trường hợp nào?

- Khi task không liên quan đến UI hoặc frontend.
- Khi dự án không dùng React, Tailwind hoặc shadcn/ui.
- Khi chỉ cần logic xử lý dữ liệu, backend, API, hay nghiệp vụ thuần.
- Khi muốn thay đổi nhỏ ngoài phạm vi giao diện và không cần component system.
- Khi kiến trúc dự án có design system riêng và không dùng stack này.

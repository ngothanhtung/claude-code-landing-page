# web-design-guidelines

## Công dụng

Skill này dùng để review mã giao diện web theo bộ Web Interface Guidelines mới nhất. Trọng tâm là kiểm tra mức độ tuân thủ về UI/UX, accessibility và best practices thông qua một checklist chuẩn được lấy từ nguồn chính thức.

## Lợi ích

- Chuẩn hóa quy trình review UI theo một bộ quy tắc thống nhất.
- Giảm rủi ro bỏ sót lỗi trải nghiệm và accessibility.
- Luôn cập nhật vì guideline được fetch mới trước mỗi lần review.
- Kết quả review rõ ràng, ngắn gọn theo dạng file:line, dễ sửa trực tiếp.
- Hữu ích cho audit chất lượng trước khi merge hoặc release.

## Dùng trong trường hợp nào?

- Khi cần review UI tổng thể cho website hoặc web app.
- Khi cần kiểm tra accessibility và UX theo chuẩn.
- Khi muốn audit thiết kế hoặc kiểm tra tuân thủ best practices giao diện.
- Khi có yêu cầu như review my UI, check accessibility, audit design, review UX.
- Khi cần rà soát các file cụ thể hoặc theo pattern file.

## Không nên dùng trong trường hợp nào?

- Khi công việc không liên quan đến giao diện web.
- Khi chỉ làm backend, API, database, hạ tầng hoặc automation.
- Khi cần tạo mới UI từ đầu mà chưa có file để review.
- Khi cần review native mobile UI theo guideline riêng của iOS/Android.
- Khi cần phân tích hiệu năng hệ thống thuần backend không liên quan UX/UI.

## TechStacks liên quan đến skill này

- Web UI (HTML/CSS/JavaScript/TypeScript)
- Frontend frameworks (React, Next.js, Vue, Svelte...)
- Accessibility standards (a11y, semantic HTML, ARIA)
- Quy trình code review/audit UI
- Remote guideline source: vercel-labs/web-interface-guidelines
